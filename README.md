# Kexborn - YouTube Downloader ✊

Удобное десктопное приложение для скачивания видео и аудио с YouTube. 
Создано с использованием Python, CustomTkinter и yt-dlp.

## Особенности
- 🎵 Скачивание аудио в формате MP3 (192 kbps).
- 🎬 Скачивание видео в максимальном качестве (вплоть до 1080p и выше со склейкой звука).
- 📁 Поддержка скачивания целых плейлистов (автоматически создает папку).
- 📊 Наглядный Progress Bar и история недавно скачанных файлов.
- 🔄 Автоматическая проверка обновлений.

## Установка (для пользователей)
1. Перейдите в раздел **Releases** справа на этой странице.
2. Скачайте архив `Kexborn-YTDL-v1.0.zip`.
3. Распакуйте архив в любую папку.
4. Запустите `Kexborn - YouTube Downloader.exe`. 
*(Внимание: файл `ffmpeg.exe` всегда должен лежать в одной папке с программой для корректной работы).*
